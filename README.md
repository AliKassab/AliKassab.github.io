## Launch Explore with me

The page is hidden from navigation and redirects to Home while disabled.
Preview locally at `/explore.html?preview=explore` on localhost.
In `scripts/config.js`, set `explore.endpoint` to your answer API and
`explore.enabled` to `true` when ready. The API receives a JSON POST with
`questionId` and `answer`; return a 2xx status only after storing the answer.
Remove the `noindex` robots meta tag from `explore.html` at launch.
